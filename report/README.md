# 课程交付

这里存放报告源文件、导出 PDF、演示材料和视频链接。代码整理不会自动完成课程提交。

建议按原任务书撰写：

1. 项目动机、论文对应章节及简化范围。
2. 组件设计、持久化格式、稀疏索引与查询流程。
3. 正确性验证、E1 机制实验、E2 原生验证、E3 小规模三系统对照。
4. 已保留的失败实验、局限及个人贡献。
5. 参考文献、外部 SQL 来源、GitHub 与视频链接。

实验数字和图表应引用 `results/` 中相应 suite。新的本地工程检查保存在
`build/project-check/`，仅证明整理后的代码可构建及回归通过。

责任人、组员、教师确认范围及截止日期按真实情况填写。
